# Cartes En Ligne

Create a premium one-page website for CityTimelineMod, an experimental Cities: Skylines II geospatial mod.

Visual direction: dark GIS/cartography interface, elegant and technical, inspired by satellite maps and professional mapping software — anthracite background, subtle grid/topography, cyan/blue geographic lines, restrained animations, strong typography. Avoid generic SaaS styling.

Hero: “Build cities from the real world.” Explain that CityTimelineMod loads RealMap GeoJSON bundles, renders roads, water, zoning and rail overlays, provides terrain calibration, and experiments with a 57.344 km LargeMap / PlayableWorld system.

Add sections: Overview, 57 km World, Geospatial Layers, Technical Architecture, Development Status, and Open Source with a prominent GitHub button to https://github.com/Giscolab/CityTimeline-Mod. Clearly label experimental features; do not invent finished features.

Make it responsive, visually impressive and lightweight. Use React/Vite only, no backend, Supabase, authentication or database. Make it GitHub Pages compatible under /CityTimeline-Mod/, with correct asset paths, SEO/OpenGraph metadata and a GitHub Pages Actions deployment workflow.
